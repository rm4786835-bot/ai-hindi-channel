# पाँच सौ का challan
@ shocked young indian man reading phone close up
भैया के phone पर message आया। "आपकी bike का पाँच सौ रुपये का traffic challan बाक़ी है। आज नहीं भरा, तो licence रद्द।"
# एक link
@ man worried bike parking phone
साथ में एक link था, और एक file। भैया ने सोचा, पाँच सौ ही तो हैं। File खोली, app install हुआ, सारी permissions दे दीं।
# रात को
@ phone screen otp messages dark room
रात को phone पर OTP आने लगे। जो उन्होंने माँगे ही नहीं थे।
# असली बात
@ young man relieved sister explaining phone
असली challan का message किसी app file के साथ नहीं आता। Challan सिर्फ़ सरकारी e challan parivahan website पर ख़ुद number डालकर देखिए। और ठगी हो, तो तुरंत एक नौ तीन शून्य पर call कीजिए।
