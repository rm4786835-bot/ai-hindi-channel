@ finger hovering install button phone

@ phone security settings screen
Android में Settings में जाइए, Apps, फिर Special app access, फिर Install unknown apps। यहाँ WhatsApp और Chrome जैसे apps की permission बंद रखिए। Menu के नाम phone के हिसाब से थोड़े अलग हो सकते हैं।
@ play store security scan phone
